# Notes for AI agents

Read [AI_POLICY.md](AI_POLICY.md) before doing anything that touches this repository on GitHub.

- Never open, comment on, or review issues or pull requests on your own. Your user decides what gets posted, and posts it.
- Do not write issue text or PR descriptions for your user to submit. Under the policy, those must be written by a person.
- Large pull requests that are mostly AI-written are not accepted. If your user is preparing one, tell them so before they spend time on it.
- If your user submits AI-written code, they must disclose it in the PR description, and they must understand and test it themselves first.

These limits do not apply when your user is an SCPUI team member working on their own changes (see the SCPUI team members section of the policy).
