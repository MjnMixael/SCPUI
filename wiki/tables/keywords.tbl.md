![SCPUI 0.13.0](https://raw.githubusercontent.com/wiki/MjnMixael/SCPUI/images/badges/scpui-0.13.0.svg) The **keywords.tbl** is [SCPUI](Home)'s extension of the [color tag](https://wiki.hard-light.net/index.php/Briefing_Text) system. It allows styling important words throughout the briefing UIs without having to use inline color tags (although they are supported, under a different syntax, for one-off words). Keywords can also be given tooltips.

This table is one of the Modular Tables and can be extended with **xxx-kwrd.tbm**. Global prefixes and suffixes defined in keywords.tbl also apply to every -kwrd.tbm. Global prefixes and suffixes defined in a -kwrd.tbm apply only within that file.

## Notes

- Keyword matching is performed in briefings (including loop and red alert briefings), command briefings, debriefings, and the fiction viewer. It utilizes SCPUI's HTML support, so they must be put into [HTML mode](https://wiki.hard-light.net/index.php/Briefing_Text). Keyword matching is *not* performed inside preexisting HTML tags, allowing them to override keywords. `<span class='green italic'>Iceni<$slashspan>` will render as *Iceni* in green, even if "Iceni" is keyworded as red italics normally.
- Keyword matching uses a system of prefixes and suffixes to provide flexibility. When a keyword is matched, if it follows one of its prefixes, is followed by one of its suffixes, or both, the prefix and/or suffix is treated as part of the keyword. Prefixes and suffixes can be *separate*, meaning they're their own word (or words), or *immediate*, meaning that they're part of the word they attach to. An example of the former would be ship prefixes like GTD or SC. An example of the latter would be the English possessive marker "'s".
- Prefixes and suffixes are usually defined per keyword, but may be defined globally as well. A keyword always matches on its own too, with no prefix or suffix.

## Format

- Defines colors and tooltips for the briefing UIs throughout the SCPUI interface system.
- Table begins with **#Default** and ends with **#End**.
- ![SCPUI 1.0.0](https://raw.githubusercontent.com/wiki/MjnMixael/SCPUI/images/badges/scpui-1.0.0.svg) Translations are supported with additional sections using the language name as in the example below.
- The language name is the full name of the game's current language as reported by the engine (for example `#French` or `#German`). If a section for the current language exists, only that section is read and #Default is ignored. Otherwise only #Default is read. If neither exists, the file adds no keywords.
- Each section ends with its own #End.

```text
#Default

;;table data

#End

#French

;;table data

#End
```

## #Default

- This section defines the basic keyword colors and tooltips.
- The global prefixes and suffixes below must come before the first `$Style:`.

### +Prefix:

- Define a globally-available separated prefix (see [Notes](#notes)).
- Can be listed multiple times.
- Syntax: **String**

### +Immediate Prefix:

- Define a globally-available immediate prefix (see [Notes](#notes)).
- Can be listed multiple times
- Syntax: **String**

### +Suffix:

- Define a globally-available separated suffix (see [Notes](#notes)).
- Can be listed multiple times
- Syntax: **String**

### +Immediate Suffix:

- Define a globally-available immediate suffix (see [Notes](#notes)).
- Can be listed multiple times
- In English, this is typically used for plurals (s, es) and possessives ('s).
- Syntax: **String**

### $Style:

- Begin defining a keyword, and define the CSS class(es) associated with it.
- The string here should be a CSS class from common.rcss, or multiple such classes separated with spaces.
- The prefixes and suffixes for this style must come before its first `+Text:`. They are added to the global ones rather than replacing them.
- A `$Style:` with no `+Text:` entries is reported with a warning.
- Syntax: **String**

#### +Prefix:

- Define a separated prefix for this keyword (see [Notes](#notes)).
- Can be listed multiple times.
- An example would be GTD for a keyword representing a list of destroyers.
- Syntax: **String**

#### +Immediate Prefix:

- Define an immediate prefix for this keyword (see [Notes](#notes)).
- Can be listed multiple times.
- Syntax: **String**

#### +Suffix:

- Define a separated suffix for this keyword (see [Notes](#notes)).
- Can be listed multiple times.
- Common examples include listing Roman numerals for planets orbiting a star, or digits after a wing name.
- Syntax: **String**

#### +Immediate Suffix:

- Define an immediate suffix for this keyword (see [Notes](#notes)).
- Can be listed multiple times.
- Syntax: **String**

#### +Text:

- The actual keyword to apply this style to.
- Can be listed multiple times.
- If the same keyword (including a prefix or suffix combination) is already registered with a different style, a warning is shown and the new one is skipped.
- There's no actual requirement that this be a single word - e.g. "Beta Aquilae" is perfectly valid.
- Syntax: **String**

##### ++Tooltip:

![SCPUI 1.0.0](https://raw.githubusercontent.com/wiki/MjnMixael/SCPUI/images/badges/scpui-1.0.0.svg)

- A tooltip to add to this specific keyword. Will show up if the mouse is hovered over the keyword.
- This applies *only* to the previous +Text: entry (and its prefix and suffix combinations).
- Must directly follow that +Text: entry.
- Syntax: **String**

## Sample

```text
#Default

; Possessive markers
+Immediate Suffix: '
+Immediate Suffix: 's

; Friendly wings, and specific ships within those wings, are blue.
$Style: blue
+Suffix: 1
+Suffix: 2
+Suffix: 3
+Suffix: 4
+Text: Alpha
+Text: Beta
+Text: Gamma
; Delta, Epsilon, etc. omitted for brevity

; Stars and planets are yellow.
$Style: yellow
+Suffix: I
+Suffix: II
+Suffix: III
+Suffix: IV
+Suffix: V
+Suffix: VI
+Suffix: VII
+Suffix: VIII
+Text: Antares
+Text: Beta Aquilae
+Text: Delta Serpentis

$Style: blue
+Text: RIO
++Tooltip: Radar Intercept Officer
+Text: SAR
++Tooltip: Search and Rescue
+Text: OrBat
++Tooltip: Order of Battle

$Style: blue
+Immediate Suffix: s
+Text: Terran
+Text: Vasudan

$Style: green italic
+Prefix: GTD
+Text: Amadeus
+Text: Bastion
+Text: Delacroix
+Text: Eisenhower
+Text: Galatea
+Text: Goliath
+Text: Intrepid
+Text: Krios
+Text: Legion
+Text: Malendroke
+Text: Minnow
+Text: Nereid
+Text: Soyakaze
+Text: Uhuru
+Text: Vienna
; "Intrepid", "Intrepid's", "GTD Intrepid", and "GTD Intrepid's" will all be green and italicized.

#end
```
