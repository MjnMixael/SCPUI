![SCPUI 0.12.0](https://raw.githubusercontent.com/wiki/MjnMixael/SCPUI/images/badges/scpui-0.12.0.svg) The **journal.tbl** is used by [SCPUI](Home)'s Journal extension to define the journal options and entries for a specific campaign. The Journal is configured on a per-campaign basis where each campaign loads from a table matching the format `CAMPAIGN_FILE_NAME-journal.tbl`.

This table is NOT modular, by design, and cannot be extended.

Code: [/journal_ui/data/scripts/scpui_ext_journal.lua](https://github.com/MjnMixael/SCPUI/blob/development/journal_ui/data/scripts/scpui_ext_journal.lua). See [Tables](Tables) for every table.

Badges show the SCPUI version a field or behavior was added in. Fields without a badge arrived with the table.

## Format

- Defines the journal options, configuration, and available entries
- Every section is optional, but the sections that are present must appear in this order: **#Journal Options**, **#Journal Sections**, **#Journal Entries**.
- Each section ends with its own **#End**

## #Journal Options

- The base configuration options
- Must end with #End

### $Title:

- Optional. The title of the UI shown to the player.
- XSTR is supported.
- Syntax: **String**
- Default: **Journal**

## #Journal Sections

- Defines what sections or entry categories are available.
- Can define up to 3 sections. Any additional section is skipped with a warning.
- Must end with #End

### $Name:

- The name of the section. Entries reference this name in `$Group:`.
- Use plain text, not XSTR("",  ##). Translation is handled by `$XSTR:`.
- Syntax: **String**

### $XSTR:

- Required. The XSTR ID for the section name.
- Syntax: **Integer**

## #Journal Entries

- Defines all available journal entries
- Must end with #End

### $Name:

- The name of the entry.
- Use plain text, not XSTR("",  ##). Translation is handled by `$XSTR:`.
- Syntax: **String**

### $XSTR:

- Required. The XSTR ID for the entry name.
- Syntax: **Integer**

### $Group:

- Required. The Section or Category that this entry belongs to. Must match a section `$Name:` (case-insensitive).
- If no section matches, SCPUI shows a warning and the entry is skipped.
- Syntax: **String**

### $Visible by Default:

- Optional. Sets whether this entry is always visible or must be unlocked.
- Syntax: **Boolean**
- Default: **false**

### $Short Title:

- Optional. A short title string for the entry. This is the key used to unlock the entry with the `lua-journal-unlock-article` SEXP.
- The value is converted to lowercase and every run of characters that are not letters or numbers becomes a single `_`, with leading and trailing `_` removed. For example `bta1_head01` stays `bta1_head01` and `Living In Antares` becomes `living_in_antares`.
- If not provided, the key is built the same way from `$Name:`.
- Syntax: **String**

### $File:

- Required. The base name of the text file to use for the journal entry. The file is loaded from `data/fiction`.
- Language support is handled by appending FSO's language shorthand to the filename before the extension `BASENAME-lang.txt`. If that file does not exist, the base file is used.
- Must be a .txt file and the extension should be included here.
- Syntax: **String**

### $Image:

- Optional. The image file to display (without extension).
- If not provided no image will be displayed.
- Syntax: **String**

### $Caption:

- Optional. The caption for the image. Ignored if there is no image to display.
- If not provided no caption will be displayed.
- Syntax: **String**

### $Caption XSTR:

- The XSTR id for the caption.
- Required if Caption is provided, and must directly follow it.
- Syntax: **Integer**
