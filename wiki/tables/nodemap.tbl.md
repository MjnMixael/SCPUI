![SCPUI 1.1.0](https://raw.githubusercontent.com/wiki/MjnMixael/SCPUI/images/badges/scpui-1.1.0.svg) The **nodemap.tbl** is used by [SCPUI](Home)'s Node Map extension to define the node map and its progression within a mod's Node Map UI screen.

This table is one of the Modular Tables and can be extended with **xxx-nmap.tbm**.

Code: [/nodemap_ui/data/scripts/scpui_ext_nodemap.lua](https://github.com/MjnMixael/SCPUI/blob/development/nodemap_ui/data/scripts/scpui_ext_nodemap.lua). See [Tables](Tables) for every table.

## Format

- Defines the map options, configuration, and layout.
- Every section is optional, but the sections that are present must appear in this order: **#Node Map Icons**, **#Node Map Colors**, **#Node Map Systems**.
- The whole file ends with a single **#End** after the last section. This applies to every -nmap.tbm as well, since each one is parsed as a complete table.

## #Node Map Icons

- Defines the available icons, assigned as Colors for each map system.

### $Name:

- The name of the icon. Usually a color.
- Not case-sensitive.
- Syntax: **String**

#### +File Base:

- Required. The image file to use for the icon.
- Any extension is stripped.
- Syntax: **String**

## #Node Map Colors

- This section is shorthand to define colors used for the nodes attached to each system.

### $Name:

- The name of the color.
- Not case-sensitive.
- Syntax: **String**

#### +Red:

- Required. The red value for the color.
- Clamped to 0-255.
- Syntax: **Integer**

#### +Green:

- Required. The green value for the color.
- Clamped to 0-255.
- Syntax: **Integer**

#### +Blue:

- Required. The blue value for the color.
- Clamped to 0-255.
- Syntax: **Integer**

## #Node Map Systems

- Defines all the systems on the map and their location

### $Name:

- The name of the system.
- Must be unique. A duplicate name is an error.
- Syntax: **String**

### $Display Name:

- Optional. The name as displayed to the player.
- Syntax: **String**
- Default: the `$Name:` value

### $Hide Label:

- Optional. Hides the system name if true.
- Syntax: **Boolean**
- Default: **false**

### $Description:

- Optional. The description of the system.
- Syntax: **String**
- Default: an empty string

### $Controlling Faction:

- Optional. The name of the controlling faction of the system.
- Syntax: **String**
- Default: an empty string

### $Type Of System:

- Optional. The type of the system (binary, trinary, etc).
- Syntax: **String**
- Default: an empty string

### $X Coordinate:

- Required. The X coordinate of the system on the map, as a fraction of the map width.
- Clamped to 0-1.
- Syntax: **Float**

### $Y Coordinate:

- Required. The Y coordinate of the system on the map, as a fraction of the map height.
- Clamped to 0-1.
- Syntax: **Float**

### $Color:

- Required. The Color of the system. Should be one of the Node Map Icons listed in the [#Node Map Icons](#node-map-icons) section (not case-sensitive).
- If no icon with that name exists, SCPUI shows a warning and uses `green`.
- Syntax: **String**

### $Visible:

- Optional. Whether or not the system is visible on the map.
- Syntax: **Boolean**
- Default: **true**

### $Selectable:

- Optional. Whether or not the system is selectable on the map.
- Syntax: **Boolean**
- Default: **true**

### $Node:

- Defines a node for the system. Each system can have unlimited nodes. Nodes are automatically connected to each other based on these configuration settings.
- The value should be the node name and must be unique within the system. A duplicate node name in the same system is an error.
- Syntax: **String**

#### +Angle:

- Required. The degree where the node should be placed around the system it is attached to. 0 is straight up and the angle increases clockwise.
- Syntax: **Integer**

#### +Color:

- Required. The color the node should be drawn with. Should match one of the [#Node Map Colors](#node-map-colors) defined above (not case-sensitive).
- If no color with that name exists, SCPUI shows a warning and uses `blue`.
- Syntax: **String**

#### +Enforce Line Color:

- Optional. If true, the line color from this node will always attempt to match the color of the node. Hierarchy of the table may change expected behavior.
- Syntax: **Boolean**
- Default: **false**

#### +Do Not Connect:

- Optional. If true, there will be no line connecting this node to another node ever.
- Syntax: **Boolean**
- Default: **false**

### $Progression:

- Begins a progression definition that overrides all previous values based on the mod's custom progression system.
- Progression is defined through the `nodemap.progressionFunction` UI Topic, which returns a function. The value here is passed to that function, which should return a number. Without a custom function every progression gets a value of 1.
- A progression applies once the player's current progress (from the `nodemap.progress` UI Topic) is greater than or equal to its value. If several apply, the one with the highest value wins.
- Syntax: **String**

#### +Description:

- Optional. The new description to use for this progression.
- Syntax: **String**

#### +Append Description:

- Optional. The string to append to the most recent full description.
- Syntax: **String**

#### +Controlling Faction:

- Optional. The new controlling faction to use for this progression.
- Syntax: **String**

#### +Color:

- Optional. The new color to use. Should be one of the previously defined icons (not case-sensitive).
- If no icon with that name exists, SCPUI shows a warning and uses `green`.
- Syntax: **String**

#### +Node:

- Optional. Defines a progression for a specific node. The value should be the name of the node to progress.
- Syntax: **String**

##### +Color:

- Optional. The new color to use. Should be one of the previously defined colors (not case-sensitive).
- If no color with that name exists, SCPUI shows a warning and uses `blue`.
- Syntax: **String**

##### +Enforce Line Color:

- Optional. The new enforcement value to use.
- Syntax: **Boolean**

##### +Do Not Connect:

- Optional. The new connection value to use.
- Syntax: **Boolean**
